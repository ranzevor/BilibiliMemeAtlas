# v0.1.5 — 早期热梗研究与来源体系完善

## 主要变化

- 按独立研究项补充并核对「教练，我想打篮球」「FFF团」「德国骨科」「日和中文配音」「钉宫病」「和我签订契约，成为魔法少女吧」「Nice boat」「妮可妮可妮」「已经没什么好害怕的了」「喵帕斯」等历史热梗的含义、原作线索与传播语境。
- 完善「⑨」「阿卡林」「含金量还在上升」「我是真人」「哼哼啊啊啊」「XX世界巡演」「外星小绿猫」等条目的来源记录与事实边界。
- 区分原作创作时间、公开刊载或播出时间、视频上传日期、后续添加的可变标签以及不同平台的传播证据；不将二手回顾或当前标签误作首发记录。
- 区分《魔法少女小圆》原 TV 动画第 1 话与后续 TV Edition 的同序号标题；依据《悠哉日常大王》原作者访谈，区分最先创作的故事与后来刊载的第 1、2 话顺序。
- 加强同一词条的来源引用约束，更新来源与权利登记、词条目录、覆盖统计、年代索引及针对性回归测试。

## 语料规模

本版收录 **303 个词条、391 条来源**，比 v0.1.4 增加 58 条来源。词条中已核实 55 条、部分核实 248 条。来源读取范围为全文 189 条、摘要 138 条、元数据 64 条。资料核查截止日为 **2026-11-11**。

年代分类、来源状态、来源限制以及仍待补证的命题，见发行中的词条目录、历史索引、来源记录和覆盖摘要。资料核查截止日与软件发布日期分别管理。

## 兼容与安装

沿用既有稳定词条与来源 ID、查询命令和数据结构。运行基线为 **CPython 3.10+**，仅使用 Python 标准库。
