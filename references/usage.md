## 先判断语境

判断说话者回应什么、对谁说、是否反讽，以及画面当前发生了什么。只有词条而无上下文时，给常见含义和必要的另一种解释；不要把最熟悉的意思强加到全部场景。

| 线索 | 处理方式 |
| --- | --- |
| 名场面切片、复刻与周年回顾 | 保留原作、改写与复刻的关系；较老的表达可以自然成立 |
| 技术教程、知识科普 | 围绕具体方法、结果或学习体验表达；保证技术事实完整 |
| 游戏、电竞、直播 | 核对游戏、角色、赛季和对局；同一数字或简称可能有多个对象 |
| 动画、影视 | 区分原作台词、翻译、中文空耳和网友续写；避免透露未出现的剧情 |
| 音乐、鬼畜 | 区分原曲、采样、人力音源、填词、音MAD、二创PV与再投稿 |
| 日常分享、宠物 | 按当代常见语义解释，问出处时补原义与迁移 |
| 公告、故障说明、争议回应 | 先保证事实和动作清楚；无适配的梗时用普通语言 |

这些是写作选择，不是对分区观众统一口味的断言。用户给出的目标语气优先于默认示例。

## 按表达位置处理

弹幕附着于视频的时刻，短而即时的反应容易与画面结合。评论可补前因后果，讨论细节或说明评价。标题、简介和长文承担准确描述的任务，不因使用流行语而掩盖内容。直播互动还要看主播当时的上下句与既有约定。

先形成一句不依赖梗也能说清楚的意思，再选择是否替换其中一处。若一个梗需要额外长解释才能成立，优先保留原句。不把“懂梗”表演成固定密度的缩写、感叹号、表情和口号。

## 语义转换与常见误读

| 现象 | 检查内容 |
| --- | --- |
| 反讽 | “真有你的”“谢谢你”等未必是字面赞美；看对象和前后句 |
| 模板槽位 | 句式内部虚构的信息不能转成事实 |
| 同词多义 | “典”“急”“孝”“寄”等单字须结合圈层，不能只按单字符检索整段话 |
| 空耳 | 模仿听感的中文不等于外语原义；解释时明确哪一层是空耳 |
| 二创名言 | 配音/字幕不能作为真实人物言论；找不到原始讲话就不要归给本人 |
| 数字与字母 | 先看游戏、人物、作品和上下文；巧合数字不自动触发梗义 |
| 同名复兴 | 新视频带火旧素材时，分开原素材时间与再次传播 |
| 梗与基础术语 | UP主、弹幕、投币首先是平台概念，不计入历史热梗覆盖量 |

## 写作示例

以下是原创写作示例，不是热度或出处证据。

**技术教程。** 原意：“这个例子让我理解了索引为什么有效。”可写：“看到执行计划那一段，终于把索引这事想明白了。”若明确要求稍带梗，可写：“脑子：这次真会了。手：等我自己跑一遍。”不能把未运行的实验写成亲自跑过。

**手工制作。** 原意：“过程看起来简单，自己做应该很难。”可写：“每一步我都看懂了，轮到自己动手估计又是另一回事。”命中相关词条后再使用其梗式表达，不必叠加无关游戏或饭圈梗。

**历史回顾。** 问老梗时，用当年的语境解释；不因今天少见就说从未存在。问今天怎么用时，避免把历史收录当成当前流行度证明。

**遇到未知梗。** 先说现有资料缺少该词条，再按用户给的上下文提出有依据的解释线索。确认出处需要原视频或前后句时说明具体缺什么，不能凭谐音编出故事。

## 人物与争议材料

历史资料可以收录攻击性表达、成人来源的非露骨称谓和群体冲突用语，供识别其语义与传播。识别性解释不等于建议用它称呼现实人物。按词条的 `sensitivity` 和 `usage.avoid` 指出与当前对象有关的问题，避免给整段内容贴笼统风险标签。

不为解释一个梗补充无关个人信息、未经证实的指控或人格诊断。真实事件与戏仿发生冲突时，保留可核实事实并说明改动之处。对于未成年人、个人灾难和疾病，不把资料中出现过的侮辱默认作为创作模板。
