# 安全边界

## 本地查询

`scripts/atlas.py` 只读取本技能的 JSON 资料，不联网、不写文件，也不执行词条或来源中的文本。未知词返回空结果；数据损坏返回明确错误，不用近似内容代替。

## 公开来源读取

`scripts/research.py` 和 `scripts/update.py discover` 只访问代码中固定的公开 B站 HTTPS 端点，不接受任意 URL、Cookie、令牌或重定向目标。单次请求有超时、响应体积和 JSON 结构上限；UTF-8 解码不接受重复字段或非标准数值。拒绝、验证码、登录要求、限流和网络错误均停止相应读取，不自动重试或绕过。

联网返回的标题、简介、榜单和统计只作为研究线索。它们不证明视频内容、台词、首创、热度或词义，也不能直接提高条目的证据等级。

## 本地更新

`preview` 在临时目录校验提案和派生内容，不修改知识库。`apply --write` 只允许变更 `references/` 中已定义的语料、来源、元数据和确定性派生文件；提案须绑定当前资料版本和被替换记录，重复 ID、悬空引用、弱证据升格、同名义项冲突及并发变化均拒绝。

写入使用与安装目录生命周期共享的写入租约、变更前记录和失败回滚。结束阶段先原子移走活动锁名，不在活动名下销毁最后的可解释状态。持续介质错误可能留下待恢复或已提交待清理记录；恢复仅处理可识别且未出现未知修改的文件。该机制不是断电级多文件事务，也不能约束不遵守互斥规则的外部写入者。

## 归档与本地目录替换

归档器只接受项目白名单内的普通文件，并把输出限制在项目目录之外。安装器要求调用者提供归档摘要和已存在父目录，拒绝符号链接父路径、路径穿越、特殊归档成员、大小写冲突、超限内容和不完整项目。升级、卸载与恢复均绑定运行时目录身份；未知修改、并发变化或已存在恢复目标会使操作停止。

旧目录、卸载目录和已进入目标后又失败的新目录均保留在同一父目录，不由脚本删除。安装目录操作与知识更新共用写入租约，中断恢复只处理操作记录中登记的相对成员；未知目标出现时不覆盖且保留锁，暂存内容不作为恢复成功的清理对象。已提交待清理只能在精确身份回读通过后完成，不转为回滚。

## 离线发行核对

发行工具只比较本地源码、说明、归档、校验和文件，以及调用者已经取得的元数据。它不读取凭据、不连接托管服务，也不执行标签创建、上传或发布。可安装核对只接受 `skill_zip`，并要求回读仓库、标签最终提交、资产长度和可信摘要与本地合同一致。元数据相符只说明所给输入之间一致；回读值的真实性和外部动作授权须由实际调用方另行成立。

## 不属于本技能的动作

查询和维护接口不登录账号，不发送弹幕、评论、私信，不关注、投币或下载视频，不调用付费服务，不创建定时任务，也不执行公开发布。第三方内容的使用范围见根目录 `CONTENT_RIGHTS.md`。
