## 平台与历史

B站公司介绍将网站创立时间记为2009年6月、正式命名“哔哩哔哩”记为2010年1月。早期ACG背景与今天生活、游戏、娱乐、科技、知识等多种内容并存，不能把全站受众视作同一个圈子。[公司介绍](https://ir.bilibili.com/cn/corporate-information/?tab=company-profile) 的登记依据来自公开搜索索引；内容页读取返回403，不据此判断页面已经失效。

这份资料用三个历史区间组织查询，不把区间当作官方分期。来源于其他站点、作品或现实事件的素材，可以在B站经历二创、反复使用和语义变化。溯源时按具体节点查证。

## 互动概念

| 概念 | 阅读时的基本理解 | 容易混淆之处 |
| --- | --- | --- |
| UP主 | 投稿创作者的社区称呼 | 不直接表示职业、收入、粉丝规模或与平台的雇佣关系 |
| 弹幕 | 与播放时间关联、显示在视频画面上的评论 | 与评论区、直播聊天的上下文和显示方式不同 |
| 评论 | 视频或动态下可展开讨论的内容 | 不一定对应一个精确视频时刻 |
| 一键三连 | 点赞、投币、收藏这一组合 | 关注、充电、分享不属于这三个动作 |
| 投币与充电 | 不同的互动和支持功能 | 解释梗时不把投币直接换算成人民币，也不虚构已付费记录 |
| 分P与合集 | 组织多段内容的表达和功能 | 旧投稿结构、当前功能和用户俗称须看具体页面 |
| 空降、指路 | 在弹幕/评论中给出内容时间点的表达 | 跳转到某时刻不证明已观看前后全片 |
| 考古、补档 | 寻找旧内容与重新整理旧资料 | 新上传时间可能晚于原作，重传不等于首发 |

三连的组成有[哔哩哔哩创作中心2023年说明](https://www.bilibili.com/opus/762095209073868801)直接支持。该文中的内测资格、客户端版本和流程属于当时说明，本库不把它当作2026年的办理指南。

## 文化载体

鬼畜、音MAD、人力VOCALOID、影视剪辑、游戏实况、直播切片、翻唱、舞蹈和角色二创具有不同加工方式。辨认梗时分别看文字、声音、节奏、画面、表演动作与弹幕回应；只搜一句台词可能找不到以音乐或动作传播的素材。

“名场面”可能指原作的一幕，也可能指后来反复截取的剪辑；“空耳”是对声音的再解释，不能代替原语言翻译。跨圈传播后，原义、流行义和反讽义可能同时存在。具体条目是否足以证明这些变化，以词条证据为准。

B站[社区公约](https://member.bilibili.com/studio/convention/)的公开索引强调创作真实信息和友善交流。与任务有关的做法是围绕视频内容表达、避免把戏仿当事实、避免将无关攻击搬到创作者或其他观众身上。内容页只返回 JavaScript 提示，因此不据此概括完整现行处罚细则。
